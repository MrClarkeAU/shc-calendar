How to subscribe in Outlook (CEWA Microsoft 365)
  1. Quickest: press Open in Outlook, sign in if asked, check the name, then choose Import.
  2. By hand: press Copy link, open outlook.office.com/calendar, choose Add calendar → Subscribe from web, paste the link, name it and choose Import.
  3. Classic Outlook on Windows: Calendar → Add calendar → From Internet → paste the link → Yes.
  4. A calendar added in Outlook on the web also appears in Outlook on your laptop and phone. Tick it on or off like any other.

Outlook checks subscribed calendars every few hours, so allow up to a day for changes to appear. Subscribed events can't be edited, as they belong to the school. Events are marked Free, so they won't block meeting bookings.

Build your own

Tick what you need and watch it fill the term grid. When it looks right, download the file and import it into Outlook. Downloads don't update themselves, so download again after the calendar changes.

How to import the file into Outlook
  1. In Outlook on the web, choose Add calendar → Create blank calendar and name it “SHC 2027”. Keeping school events in their own calendar makes them easy to hide or replace.
  2. Choose Add calendar → Upload from file, pick the downloaded .ics file and select your “SHC 2027” calendar.
  3. To update: delete the “SHC 2027” calendar, create it again and upload a fresh download. Outlook doesn't reliably replace events, so starting fresh avoids duplicates.

About this page. Built by Mr Clarke for Sacred Heart College staff; not an official College website. Events come from the College's public Google calendars. Every Sunday evening the page checks them, rebuilds the ready-made calendars and refreshes this data.

Event types and departments are worked out from event titles, so a few may land in “Admin & other”. Year groups always come from the calendar an event belongs to. Assessment calendars fill up as staff add assessments.
